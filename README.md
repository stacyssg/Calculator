# Personal Calculator

An interactive Calculator web application built as part of **The Odin Project Foundations** curriculum. 
This project focuses on practicing JavaScript fundamentals, DOM manipulation, event handling, and Flexbox by building a functional calculator from scratch.
## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear functionality
- Error handling for invalid operations
- Support for consecutive calculations

## Built With

- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6)
